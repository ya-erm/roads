# Агент доски задач

`npm run agent` следит за доской задач и отдаёт задачи Claude Code в этом репозитории:

```
Новая / Доработать ──► В работе ──► Claude Code делает задачу ──► комментарий с отчётом,
                                                                 скриншотами и сохранением ──► Нужно проверить
```

- Берёт по одной задаче: сначала «Доработать», потом «Новая», внутри — старые раньше.
- Задаче без названия даёт короткое название по описанию (быстрой моделью).
- Картинки и файлы доски из описания и комментариев скачивает и передаёт Claude — он может их посмотреть, а сохранение игры из задачи — открыть.
- На доработке продолжает прежнюю сессию Claude по этой задаче, так что замечания он читает, помня, что уже сделал.
- Отчёт Claude — короткий комментарий к задаче: что сделано и как проверено, скриншоты (WebP) и файл сохранения игры для проверки (Меню → Сохранения → «Открыть из файла»).
- Что монитор делает сейчас, видно на доске по значку агента (см. ниже).
- «Проверено» ставит только человек.

## Значок агента на доске

Монитор сообщает доске свой статус — у имени токена появляется значок:

| Статус | Когда |
| --- | --- |
| `monitoring` — мониторит | ждёт задач |
| `working` — работает над задачей | от взятия задачи до публикации отчёта; по значку открывается задача |
| `waiting` — ожидает | Claude не справился, задача ждёт повторной попытки, других задач нет |
| `blocked` — нужна помощь | Claude задал вопросы или не справился, задача ждёт ответа в «Нужно проверить» |

Статус подтверждается каждые 4 минуты (на доске он живёт 5), при остановке монитора значок снимается. Имя у значка — название токена. `--dry-run` статус не трогает.

## Подготовка

1. Токен доски: на сервисе досок «Настройки → доска → API-токены», право `write`.
2. `cp .env.example .env` и заполнить `TASKS_BASE_URL`, `TASKS_BOARD` (slug из адреса доски), `TASKS_TOKEN`. Файл `.env` не коммитится.
3. Claude Code (`claude`) установлен и авторизован.
4. Для скриншотов нужен Chromium Playwright: `npx playwright install chromium` (или `TASK_AGENT_BROWSER_CHANNEL=chrome` — установленный Google Chrome).

## Запуск

```sh
npm run agent                  # следить за доской, пока не остановят
npm run agent -- --dry-run     # показать очередь, ничего не меняя
npm run agent -- --once        # разобрать текущую очередь и выйти
npm run agent -- --task <id>   # брать только эту задачу
```

Ctrl+C во время работы — остановиться после текущей задачи, второй Ctrl+C — прервать её сразу (задача вернётся в прежний статус, при следующем запуске сессия Claude продолжится). Если монитор упал посреди задачи, при следующем запуске он вернёт её в очередь.

Задачи выполняются в рабочем дереве этого репозитория. По умолчанию изменения не коммитятся — их видно в `git diff` и в запущенном dev-сервере. `TASK_AGENT_COMMIT=true` — один коммит на задачу (без push).

## Скриншоты и сохранения

Claude снимает игру через `npm run shot` — тот же инструмент можно запускать и вручную:

```sh
npm run shot -- --url /test/bus --out shot.png --export-save save.json
npm run shot -- --save save.json --speed 0 --camera 1200,800,1 --out after.png
npm run shot -- --help
```

Берёт запущенный dev-сервер (`TASK_AGENT_GAME_URL`, по умолчанию `http://localhost:4800`), иначе поднимает свой. Партия открывается в отдельном слоте сохранений и игру пользователя не трогает.

## Где что лежит

`.task-agent/` (не коммитится; другая папка — `TASK_AGENT_STATE_DIR`):

- `state.json` — сессии Claude по задачам, неудачные попытки, неопубликованные отчёты;
- `runs/<задача>/<запуск>/prompt.md` — задание, которое получил Claude;
- `runs/<задача>/<запуск>/claude.jsonl` — весь ход работы Claude (stream-json);
- `runs/<задача>/<запуск>/input/` — вложения задачи, `out/` — скриншоты и сохранения для отчёта.

## Сбои

- Claude упал или не уложился во время — задача возвращается в прежний статус и берётся снова через `TASK_AGENT_RETRY_MINUTES`; после `TASK_AGENT_MAX_ATTEMPTS` попыток — комментарий с ошибкой и «Нужно проверить».
- Claude не понял задачу — отчёт с вопросами («Нужны уточнения») и «Нужно проверить»: ответьте комментарием и верните задачу в «Доработать».
- Не удалось опубликовать отчёт (нет сети) — он остаётся в `state.json` и публикуется при следующей проверке доски, без дублей.
- Статус задачи поменяли, пока Claude работал, — отчёт публикуется, статус остаётся тем, что поставил человек.

## Безопасность

- Кто может писать на доску, тот ставит задачи Claude Code на этой машине. Режим разрешений по умолчанию — `auto` (Claude сам оценивает, что безопасно); `TASK_AGENT_PERMISSION_MODE` — другой режим.
- Claude не получает токен доски: статусами и комментариями управляет только монитор.
- К отчёту прикладываются только картинки и `.json` из папки `out/` этого запуска; токен доски из текста отчёта вырезается.
- Скачиваются только файлы с сервиса досок (`<TASKS_BASE_URL>/images/…`). Загрузчик файлов сервиса публичный: всё приложенное доступно по ссылке.

## Настройки

Все — переменные окружения или `.env`, образец с пояснениями — [`.env.example`](../.env.example).

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `TASKS_BASE_URL`, `TASKS_BOARD`, `TASKS_TOKEN` | — | сервис досок, slug доски, токен |
| `TASK_AGENT_ACTOR` | `Claude Code` | имя исполнителя в карточках и комментариях |
| `TASK_AGENT_POLL_SECONDS` | `60` | как часто смотреть доску |
| `TASK_AGENT_MODEL`, `TASK_AGENT_EFFORT` | из настроек Claude Code | модель и усилие |
| `TASK_AGENT_PERMISSION_MODE` | `auto` | режим разрешений Claude Code |
| `TASK_AGENT_MAX_BUDGET_USD` | нет | лимит расходов на задачу |
| `TASK_AGENT_TIMEOUT_MINUTES` | `120` | лимит времени на задачу |
| `TASK_AGENT_CLAUDE_ARGS`, `TASK_AGENT_CLAUDE_BIN` | `claude` | дополнительные аргументы и команда Claude Code |
| `TASK_AGENT_TITLE_MODEL` | `haiku` | модель для названий задач |
| `TASK_AGENT_COMMIT` | `false` | коммит на каждую задачу |
| `TASK_AGENT_RESUME` | `true` | продолжать прежнюю сессию на доработке |
| `TASK_AGENT_MAX_ATTEMPTS`, `TASK_AGENT_RETRY_MINUTES` | `2`, `15` | попытки при сбоях Claude |
| `TASK_AGENT_STATE_DIR` | `.task-agent` | состояние агента, задания и журналы |
| `TASK_AGENT_GAME_URL`, `TASK_AGENT_BROWSER_CHANNEL` | `http://localhost:4800`, Chromium | для `npm run shot` |
