# Развязка

Браузерная игра про транспорт: свободно рисуешь дороги, развязки и железную дорогу, возишь людей и грузы
между городами и заводами и борешься с пробками.

**Играть:** https://roads.ya-erm.ru

Всё работает прямо в браузере, без сервера: партии сохраняются в нём же.

## Запуск

Нужен Node.js 24.

```bash
npm install
npm run dev        # игра на http://localhost:4800
npm test           # тесты (vitest)
npm run build      # сборка в dist/
npm run preview    # собранная версия на http://localhost:4801
```

## Страницы

| Адрес          | Что там                                                                 |
| -------------- | ----------------------------------------------------------------------- |
| `/`            | игра                                                                    |
| `/test/`       | тестовые сцены: автобусы, транспорт, перекрёстки                        |
| `/lab.html`    | лаборатория полос: дороги и машины без игры (на dev-сервере ещё `/test/lanes`) |

Сборка с относительными путями (`base: './'`), поэтому одна и та же `dist/` работает и на своём домене,
и в подпапке вроде `ya-erm.github.io/roads/`.

## Публикация

Каждый push в `main` собирает игру и выкладывает её на GitHub Pages
([.github/workflows/pages.yml](.github/workflows/pages.yml)).
