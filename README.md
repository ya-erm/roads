# Дороги региона

Браузерная игра про транспорт: свободно рисуешь дороги, развязки и железную дорогу, возишь людей и грузы
между городами и заводами и борешься с пробками.

**Играть:** https://roads.ya-erm.ru

Всё работает прямо в браузере, без сервера: партии сохраняются в нём же.

## Запуск

Нужен Node.js 24.

```bash
npm install
npm run dev        # игра на http://localhost:4800
npm test           # тесты (vitest)
npm run build      # сборка в dist/
npm run preview    # собранная версия на http://localhost:4801
```

## Страницы

| Адрес          | Что там                                                                 |
| -------------- | ----------------------------------------------------------------------- |
| `/`            | игра                                                                    |
| `/test/`       | каталог тестовых сцен                                                   |
| `/test/parking/` | дома, магазины и стоянки; выбор участка, пауза и шаг на кадр |
| `/test/trucks/` | семь грузовых дворов обычного размера: выбор грузовика, заезд/выезд, пауза, шаг на кадр и раскадровка в PNG; у склада — два типа подъезда |
| `/lab.html`    | лаборатория полос: дороги и машины без игры (на dev-сервере ещё `/test/lanes`) |

В тестовых сценах инструмент «Автомобили» добавляет легковые, автобусы и грузовики кликом по карте, в том числе на паузе. На легковые парковочные места помещаются легковые машины. При выборе машины доступны «Уехать» и «Поехать в…» с назначением конкретного места на карте; правый клик или Esc отменяет размещение.

Инструмент «Здания» позволяет поставить любой тип здания и настроить его вариант, размеры и парковку. У частных домов и дач можно выбрать 1–3 места, у частного гаража — 1–2 бокса. Выбор участка в тестовой панели перемещает к нему камеру.

Сборка с относительными путями (`base: './'`), поэтому одна и та же `dist/` работает и на своём домене,
и в подпапке вроде `ya-erm.github.io/roads/`.
